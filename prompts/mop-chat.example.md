# How MOP actually talks

This is a template. It is NOT loaded by anything.

Copy it to `prompts/mop-chat.md` and paste real messages from the league group
chat in. That path is gitignored, and run.py picks it up automatically once it
exists. Until then the recap's voice comes entirely from prompts/mop.md, which
is the right default - an unfilled template handed to the model as "real
messages from the group chat" is worse than no file at all.

Worth including once you do fill it:
- the bits that keep coming back
- nicknames people actually use for each other
- who gets mocked for what, and who gives it back
- how people react to a blowout, a bad beat, a bad lineup call
- anything that would confuse an outsider, which is usually the good stuff
